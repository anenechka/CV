САЙТ ДЛЯ GITHUB PAGES

В архиве лежат готовые статические файлы сайта. Сборка и установка программ не нужны.

ПУБЛИКАЦИЯ В СУЩЕСТВУЮЩЕМ РЕПОЗИТОРИИ
1. Распакуйте архив на компьютере.
2. Откройте свой CV-репозиторий на GitHub и перейдите в корневую папку (обычно это список файлов на вкладке Code).
3. Нажмите Add file → Upload files.
4. Перетащите index.html, script.js, styles.css и папку assets целиком. Если GitHub не принимает папку перетаскиванием, загрузите файлы по одному, сохранив пути assets/avatar.png, assets/favicon.png и assets/resume.pdf.
5. Подтвердите замену index.html, если GitHub предупредит о совпадении имён. Не загружайте папку Gigaide-GitHub-Pages целиком внутрь репозитория: index.html должен оказаться прямо в корне.
6. Нажмите Commit changes.
7. В репозитории откройте Settings → Pages. В разделе Build and deployment выберите Deploy from a branch, ветку main (или основную ветку вашего репозитория) и папку /(root), затем Save.
8. Подождите завершения публикации и откройте ссылку, показанную в Settings → Pages. Если открывается старая пустая версия, обновите страницу без кэша.

Все пути к сайту и его ресурсам относительные, поэтому сайт работает как в отдельном репозитории CV, так и в проектном репозитории GitHub Pages.
